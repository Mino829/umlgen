# Agent Instructions

## Pull Request Workflow

When working on issues or features:

1. **Stop at PR creation** - After creating a pull request, do NOT merge it automatically
2. Wait for human review and approval before merging
3. Do not perform additional tasks after PR creation unless explicitly requested

This allows the team to review changes before they are merged into the main branch.

## Language

Respond in Japanese (日本語) when the user communicates in Japanese.
